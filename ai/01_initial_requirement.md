# Prompt: Rust Scene Detector (OpenCV Edition)

## Роль
Ты — Senior Software Architect и эксперт по Rust-разправке. Твоя специализация — системное программирование, обработка видео и создание кросс-платформенных десктопных приложений (Tauri).

## Задача
Спроектировать и реализовать каркас приложения для детекции смены сцен в видеофайлах (MPEG) с использованием **OpenCV** вместо прямого FFmpeg. Приложение должно поддерживать два режима: GUI (Tauri) и CLI (clap).

## Технологический стек
- **Core**: Rust (latest stable).
- **Video Processing**: `opencv` crate (интерфейс к OpenCV 4.x).
- **UI**: Tauri (Frontend на выбор, Backend на Rust).
- **CLI**: `clap` (derive feature).
- **Config**: `serde` + `serde_yaml`.
- **Error Handling**: `anyhow` + `thiserror`.

## Ключевые требования
1. **Архитектура**:
   - Вынести логику обработки в отдельный модуль `core`.
   - `core` не должен знать о существовании UI или CLI.
   - Единая точка входа в `main.rs`, которая переключает режимы работы.

2. **Работа с OpenCV (Windows-first)**:
   - Использовать `VideoCapture` для чтения кадров.
   - Реализовать анализ **только в заданной зоне интереса (ROI)**.
   - Алгоритм: Конвертация ROI в Gray -> GaussianBlur -> `absdiff` с предыдущим кадром -> расчет среднего значения изменений.
   - **Важно**: Предусмотреть в `build.rs` или документации механизм линковки OpenCV под Windows (vcpkg или статические пути), чтобы избежать ошибок линковки.

3. **Конфигурация**:
   - YAML профили должны содержать: `threshold` (порог срабатывания), `roi` (x, y, width, height), `min_scene_len`.
   - CLI принимает путь к видео и путь к конфигу.
   - GUI позволяет редактировать эти параметры и визуально выделять ROI.

4. **Выходные данные**:
   - Создание папки `./Output/`.
   - Генерация `metadata.json` с таймстемпами найденных сцен и метаданными профиля.

## Что нужно сделать сейчас:
1. Опиши структуру проекта (Cargo workspace или модульная структура).
2. Напиши `Cargo.toml` со всеми необходимыми зависимостями для корректной работы `opencv` и `tauri`.
3. Реализуй модуль `src/core/config.rs` для работы с YAML.
4. Реализуй модуль `src/core/processor.rs`, содержащий основную функцию анализа видео через OpenCV.
5. Покажи пример `src/main.rs`, который разделяет запуск на GUI и CLI.

## Особое внимание:
- Обеспечь безопасность типов и обработку ошибок.
- Код должен быть идиоматичным (Rust 2021 edition).
- Добавь комментарии по настройке окружения OpenCV для Windows (переменные среды OPENCV_LINK_PATHS и т.д.).
